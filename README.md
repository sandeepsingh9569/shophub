# 🛒 ShopHub – E-Commerce Web Application

ShopHub ek modern **E-Commerce Web Application** hai jisme users products browse kar sakte hain, cart me add kar sakte hain aur orders place kar sakte hain.

---

## 🚀 Features

- User Signup & Login (JWT Authentication)
- Product Listing
- Add to Cart / Remove from Cart
- Order Placement
- Responsive UI
- Secure Backend APIs

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- Axios
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
